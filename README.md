# JS OOP Academy

A public Next.js classroom for JavaScript object-oriented programming. No accounts, no backend auth.

## What you get

- Nested left-nav for every topic in the syllabus
- Theory, sticky-note memory aids, diagrams, and generated illustrations
- Live JavaScript playground (sandboxed `iframe`)
- Multiple-choice checks
- Mini labs plus a lab exam per chapter

## Topics

Objects & classes, prototypes, inheritance, polymorphism, encapsulation, abstraction, `super`, object utilities, function-based OOP, composition, SOLID, GoF-style design patterns, and advanced OOP tradeoffs.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

Progress is stored in `localStorage` in your browser.
